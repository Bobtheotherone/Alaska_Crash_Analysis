# evidence_release/ — committed cryptographic skeleton of the final empirical run

The complete run bundle (`runs/final_<hash>/`) is **local-only**: its per-crash prediction rows are
keyed by `Crash Number`, an identifier, so it is excluded from git by `remediation/.gitignore`.
A third-round reconnaissance correctly observed that this left the delivered archive with **no**
verifiable trace of the real governed run (ART-001) — the paper pointed at a bundle the archive
did not contain, and the only complete bundle a reader could find was a synthetic fixture.

This directory is the correction. For each released final run it commits everything about the
bundle that carries **no per-crash data**:

| File | What it proves |
|---|---|
| `<run_id>/manifest.json` | the full run record: config + config hash, contract hashes, governed `data_sha256`, split manifest (aggregate), target audit (aggregate), git state at generation, environment, per-model results, paired-bootstrap CIs, calibration block, and `artifact_sha256` for every per-crash file the local bundle holds |
| `<run_id>/STATUS` | the bundle completed (`COMPLETE`) |
| `<run_id>/FROZEN.lock` | the pre-evaluation freeze: config/contract/data/split/development-report hashes + generator commit |
| `<run_id>/FINAL.done` | the one-shot marker (a second `evaluate-final` against the same freeze refuses) |
| `<run_id>/DEID_TRANSFORM.md` | the de-identification witness: original-file hash ↔ de-identified-file hash ↔ published-copy status, per file, plus metric-equality checks — generated by `make_deid_witness.py` |

The de-identified per-crash predictions themselves ship in the handoff's `evidence/` directory
(hashed by the handoff manifest), not in git. Chain narrative: `research/PROVENANCE_CHAIN.md`.

Current release run: **`final_f27613102c96`** (2012 evaluation, n = 11,630, 14 models).
