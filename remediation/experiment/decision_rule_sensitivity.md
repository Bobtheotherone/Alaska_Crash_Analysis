# Decision-rule sensitivity (DECISION-LOSS-001)

**Status:** retrospective, deterministic post-hoc analysis of the frozen 2012 predictions. No model is retrained; the hard class is re-derived from each model's already-recorded probability vector under three decision rules and ordinal MAE / accuracy recomputed. Regenerated by `python -m crashsev.decision_rule_sensitivity` (output is aggregate; no per-crash identifiers).

For an ordered target y in {0,1,2} with predicted probabilities p:
- **argmax** -- minimises 0-1 loss; what the pipeline emits by default.
- **posterior median** -- smallest k with cumulative prob >= 0.5; the rule *consistent with the primary metric, ordinal MAE*.
- **expected-value round** -- round(sum_k k*p_k) clipped to [0,2].
