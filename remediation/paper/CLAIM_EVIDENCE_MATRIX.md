# Claim-to-Evidence Matrix (manuscript, v4 + correction release)

Every substantive claim in the manuscript (`paper/latex/main.tex` → released PDF; the
markdown draft `final_paper.md` is superseded) maps to its evidence. "Support" is one of:
**Generated** (from a committed machine artifact in this package), **Verified-in-source** (confirmed
in the prior project at `bb9247a` with file:line), **Design** (a produced contract/protocol),
**Cited** (external source), **Removed** (an unsupported claim deliberately dropped).

All "Generated" numbers trace to `experiment/final_results.json` (v4),
`experiment/broad_sensitivity/final_results.json`, `experiment/development_report.json`,
`experiment/leakage_factorial.json`, `experiment/decision_rule_sensitivity.md`,
`experiment/target_sensitivity.md`, the committed run skeletons under `evidence_release/`, or
`reanalysis/` — each an aggregate (no per-crash rows). Reproduction status per
`research/REPRODUCTION_LOG.md` (self-reproduction; not independent).
